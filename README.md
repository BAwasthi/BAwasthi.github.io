# Basant Awasthi: Portfolio

Personal portfolio website. I'm a Ph.D. student in Geography at Louisiana State University working on remote sensing, UAV mapping, and explainable AI for coastal wetlands.

**Live site:** https://bawasthi.github.io (published from the `master` branch)

## What's here

| File | Purpose |
|---|---|
| `index.html` | The website content |
| `style.css` | Styling (light and dark mode, works on phones) |
| `assets/Basant_Awasthi_CV.pdf` | Downloadable CV |

## Updating the site

1. Open `index.html` on GitHub and click the pencil icon (✏️).
2. Edit the text, for example to add a new publication inside the `<ol class="pubs">` list.
3. Click **Commit changes**. The live site updates within about a minute.

To replace the CV, upload a new PDF with the same name, `assets/Basant_Awasthi_CV.pdf`.
